# Pattern Play

A web game by **Perry Bonner** that teaches people to identify vintage clothing through the silhouettes and styles of sewing patterns. Each round shows flat pattern sketches from the 1930s through the 1980s and asks which one was made in a given decade. Correct guesses earn real vintage patterns for your Pattern Book, where you can restyle them in period fabrics.

- Solo project, 6 weeks
- Designed in Figma

## Play

Open the GitHub Pages link for this repo. To run it locally, serve this folder with any static server (for example `python3 -m http.server`) and open `http://localhost:8000`. Opening `index.html` directly from your files won't work, because browsers block the game's scripts that way.
